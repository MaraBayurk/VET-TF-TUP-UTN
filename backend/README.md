# Backend

## Descripción

El backend será responsable de proporcionar la API que permitirá la comunicación entre el frontend y la base de datos.

Será desarrollado utilizando:

- Node.js
- Express

## Responsabilidades

El backend será responsable de:

- Autenticación y autorización de usuarios.
- Gestión de roles y permisos.
- Gestión de usuarios.
- Gestión de mascotas.
- Gestión de turnos.
- Gestión de atenciones clínicas.
- Gestión de especialidades.
- Aplicación de las reglas de negocio.
- Comunicación con la base de datos MySQL.

## Arquitectura

La API seguirá una arquitectura organizada por responsabilidades, separando la lógica de negocio, el acceso a datos y la exposición de endpoints.

Se contemplará el uso de:

- Controladores
- Servicios
- Repositorios
- Modelos/Entidades
- Middlewares

## Seguridad

Se contemplará:

- Autenticación de usuarios.
- Autorización basada en roles.
- Protección de rutas.
- Validación de datos.
