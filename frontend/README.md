# Frontend

## Descripción

El frontend corresponde a la interfaz web del sistema de gestión de la clínica veterinaria.

Será desarrollado utilizando:

- React
- TypeScript
- SCSS

## Responsabilidades

El frontend será responsable de:

- Interfaz de usuario.
- Navegación entre las diferentes vistas.
- Formularios y validaciones de entrada.
- Gestión de sesiones de usuario.
- Visualización y gestión de mascotas.
- Solicitud y consulta de turnos.
- Consulta de la libreta sanitaria.
- Interfaces específicas según el rol del usuario.

## Roles

La interfaz contemplará diferentes funcionalidades según el rol autenticado:

- **Cliente**
- **Veterinario**
- **Administrador**

## Estructura Inicial

La estructura del frontend será definida durante la etapa de implementación del proyecto.
